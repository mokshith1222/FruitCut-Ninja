# FruitCut-Ninja 🍉🗡️

A fast-paced, high-performance mobile fruit slicing arcade game built with **Phaser 3**, **React 19**, **TypeScript**, and **Capacitor** for Android.

## Features
- **3 Game Modes**: 
  - 🏆 **Level Mode**: 30+ handcrafted progression levels with unique objectives.
  - ♾️ **Endless Mode**: Classic fruit slicing survival with combo chains.
  - ⏱️ **Time Attack**: High-octane 60-second score frenzy.
- **Juicy Game Feel**: 
  - Dynamic blade slice trails with particle bursts.
  - Directional fruit splits and splatter effects.
  - Responsive haptics and immersive audio.
- **Monetization & Ad Integration**:
  - Full Google AdMob support (Interstitials & Rewarded Video ads) with frequency protection policies.
- **Modern Clean HUD**:
  - Notch-safe layout with safe-area insets.
  - High-visibility hazard bomb rendering.

## Tech Stack
- **Game Engine**: Phaser 3
- **UI & State**: React 19, Zustand, Framer Motion
- **Tooling**: Vite, TypeScript
- **Mobile Native**: Capacitor 8 (Android)
